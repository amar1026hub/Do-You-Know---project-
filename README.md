🧠 Do You Know?

An interactive knowledge discovery and trivia web application designed to make learning addictive and engaging through micro-learning strategies.

📖 Overview

"Do You Know?" is a modern web platform built to deliver bite-sized facts, interactive quizzes, and categorized knowledge hubs. The project focuses heavily on a frictionless user experience, featuring a sleek dark-mode aesthetic with vibrant accents and unique interactive elements—including a custom dynamic scroll-reveal footer with a color-changing scissor cut animation.

✨ Features

Daily Fact Drops: Bite-sized, highly curated trivia delivered to keep users engaged and build a consistent habit of learning.

Categorized Hubs: Organized learning paths allowing users to dive deep into specific domains like Science, History, and Future Tech.

Interactive Quizzes: Gamified assessments to test knowledge retention.

Modern UI/UX: A responsive, dark-mode-first design that reduces eye strain and makes content pop across all devices (Mobile, Tablet, Desktop).

Creative Animations: Features a unique, mathematically calculated scroll animation where a color-changing scissor "cuts" the page to reveal the site footer as the user scrolls.

🛠️ Tech Stack

Frontend: HTML5, CSS3 (Custom Variables, CSS Grid, Flexbox)

Interactivity: Vanilla JavaScript (DOM manipulation, Scroll Event Listeners)

Icons: FontAwesome / Inline SVG

🚀 Getting Started

This project is built with standard web technologies and requires no complex build tools or package managers to run locally.

Prerequisites

A modern web browser (Chrome, Firefox, Safari, Edge)

Installation

Clone the repository to your local machine:

git clone https://github.com/amar1026hub/Do-You-Know---project-/tree/main 


Navigate to the project directory:

cd do-you-know


Open the index.html file directly in your web browser, or use an extension like VS Code Live Server for hot-reloading.
